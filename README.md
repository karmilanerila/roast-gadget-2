Angle-2 entry for the [One-Line Roast: The Gadget You Use Every Day](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610?ref=h379tqrk) bounty on make.fun.

## The roast

> My washing machine's 15-minute quick wash takes 58 minutes -- it lies about time the way I lie about my screen time.

A genuinely different angle from the first entry (microwave beeps): a different gadget, a different mechanism — a concrete numbers gripe (15 minutes advertised vs 58 actual) with the joke turned back on the speaker.

## How it works

`main.py` (stdlib only) writes the single roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), as plain UTF-8 bytes with mode 0644, then verifies the written bytes round-trip. Deterministic: every run writes byte-identical output.
